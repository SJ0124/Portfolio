SAM JACOB SAJAN — PORTFOLIO REDESIGN
======================================

This is the redesigned version of the portfolio.

Files:
- index.html
- style.css
- app.js
- Sam_Resume.pdf

Design:
- Editorial / minimalist visual direction
- Warm off-white paper background
- Near-black typography
- Restrained orange accent
- Large typography with generous whitespace
- Asymmetrical project layout
- Responsive mobile/tablet/desktop layouts
- Dark/light theme

A1-A10:
- Homepage, navigation, hero and tagline
- Semantic HTML5 structure
- About, Skills, Projects, Internship, Education, Contact
- Skill list and learning-path ordered list
- Education and internship presented with appropriate structured elements
- Three project cards
- Internal navigation and external GitHub/LinkedIn links
- mailto/tel/resume download
- Embedded SVG visual
- CSS Grid/Flexbox, sticky navigation, fixed back-to-top via footer anchor, hover effects, shadows
- Responsive media queries

B1-B5:
- Projects stored as JavaScript array of objects
- Project cards dynamically rendered with DOM manipulation
- Project technology filter
- Mobile hamburger navigation
- Project detail modal
- Dark/light theme
- Theme preference persisted with localStorage
- Contact form with regex validation and no page reload
- let/const, arrow functions, template literals, map/filter/forEach/find and destructuring
